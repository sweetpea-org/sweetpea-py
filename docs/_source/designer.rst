SweetPea Designer
=================

The SweetPea Designer is a graphical editor for SweetPea experiment designs. It
is meant for researchers who would rather not write Python: factors, blocks and
constraints are built with forms and menus, and the Designer generates trial
sequences and exports them as CSV.

Every design in the Designer is also a SweetPea program. A code pane shows that
program as you work, and edits made in either place update the other, so a
design can move freely between the Designer and the :ref:`SweetPea language
<home>`.

.. note::

   The Designer is at version 1 and is shared for people to try and give
   feedback on. Some SweetPea features cannot be shown in it yet; see
   :ref:`designer_limitations`.

If this is your first time using the Designer, start with
:ref:`designer_getting_started`.
